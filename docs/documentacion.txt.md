Proyecto: Sistema de Gestion para Ferretería Los Robles 



Sistema de escritorio desarrollado en Visual. NET con arquitectura conectada a una base de datos relacional. 

Su Objetivo principal es optimizar el control del inventario, la administración del producto y la clasificación para el negocio de ferreterías.



Tecnologías utilizadas:

* Lenguajes: Visual Basic.NET (VB.NET)
* Base de datos: MariaDB
* Gestor de Base de Datos: HeidiSQL
* Control de versiones: Git y GitHub
